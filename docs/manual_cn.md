# ReFocus 使用手册

## 快速开始

1. 在左侧 **提示词框** 中输入你想要生成的内容
2. 点击 **生成** 按钮
3. 等待结果出现在右侧画廊中

就这么简单。所有复杂的功能都是可选的，你只需要提示词就能开始。

---

## 辅助工具

主界面顶部提供了四个独立工具，用于图像编辑和提示词优化。

### 反推提示词（Describe）

上传一张图片，系统会自动分析并生成一段描述文字，填入提示词框。支持两种模式：

- 照片模式
- 艺术/动漫模式

### 加载元数据（Metadata）

如果你有一张之前用 ReFocus 生成的图片，里面嵌入了生成参数。上传后：

- 可以看到完整的参数记录
- 点击“应用元数据”，参数会自动加载到 UI 中，便于复现

### rembg

**rembg** 标签页提供一键背景移除功能：

1. 上传一张图片
2. 从下拉列表中选择移除模型
3. 点击“移除背景”

可用的模型与“自动生成掩码”中的四种相同：

- **isnet-general-use**：通用模型，适合大多数场景（默认）
- **u2net**：经典显著目标检测模型，速度较快
- **u2net_human_seg**：人物分割专用，适合人像抠图
- **isnet-anime**：动漫/插画风格优化，适合二次元图像

### Prompt Helper

在顶部 **Prompt Helper** 标签页中，该工具基于 `sd-webui-prompt-all-in-one-app`，提供可视化的标签式提示词构建体验：

- 按分类浏览常用提示词标签，点击即可添加至构建区
- 搜索和筛选特定风格的提示词
- 中英文翻译与格式优化

该工具在独立面板中运行，你可以在其中组合提示词，然后使用内部的“复制到剪贴板”按钮，粘贴到主提示词框中。

## 控制图像生成

如果你希望对生成过程有更多控制，勾选 **输入图像**，下方会展开三个工具面板。

### 放大与变体（UOV）

上传一张图片后，你可以：

- **变体（Vary）**：基于原图生成相似但不完全一样的版本
  - 轻微变化 → 小幅度调整
  - 强烈变化 → 更大胆的改动
  - 自定义 → 手动控制变化强度（0-1，数值越高变化越大）

- **放大（Upscale）**：将图片放大，同时补充细节
  - 选择放大倍数（0.25x - 4x）
  - 启用“快速模式”可直接放大而不经过扩散采样（速度快，但细节补充较少）
  - 勾选“忽略提示词”可使用空提示词，让模型自由发挥，适合灵感探索

### 图像提示（Image Prompt）

每个槽位接收一张参考图和一种类型。类型自己的设置（例如 Canny 的双阈值、FaceSwap 的人脸检测置信度）在该标签页勾选 **Advanced** 后出现，逐槽独立。

上传参考图，让生成结果受其影响。支持五种控制方式：

- **ImagePrompt**：提取参考图的风格或内容
- **PyraCanny**：用边缘锁定构图，适合保持姿势或布局
- **CPDS**：保留空间结构和深度
- **FaceSwap**：保持面部一致性
- **Depth**：先用 MiDaS 取参考图的深度图，再走 Stability 的 depth Control-LoRA，适合锁定画面的空间布局

每张参考图都可以独立调节：

- **停止步数**：控制网络在采样到哪一步时停止介入（数值越高影响越持久）
- **权重**：控制网络的影响强度

### 内部重绘（Inpaint）

这个标签页是一个完整的编辑器：直接在图上画或擦出遮罩（也可以上传遮罩），模型只重绘被遮住的区域。勾选 **“显示掩码生成”** 可以让系统自动生成遮罩，见下。

- **方式（Method）**：*Inpaint (default)* 是普通的按遮罩重绘；*Improve Detail (face, hand, eyes, etc.)* 适合需要更多细节的小区域；*Modify Content (add objects, change background, etc.)* 适合较大的改动
- **修复附加提示词**：只作用于遮罩区域的额外提示词

### 自动生成掩码

你可以勾选 **“显示掩码生成”**，让系统自动分析图像并生成掩码区域。模型列表与 **rembg** 的四种相同（见上方「辅助工具」）。

选择模型后点击 **“从图像生成掩码”**，掩码会自动覆盖到原图上。你仍可以在生成的掩码基础上手动调整（画笔涂抹或擦除），再执行修复操作。

## 高级设置（右侧面板）

勾选主界面的 **高级** 复选框，右侧会展开设置面板。

右侧栏分三个标签页：**Settings** 放日常参数，**Models** 放模型选择，**Advanced** 放只在专门调参时才用得到的项。Settings 里的控件按常用程度从上到下排。

### 基本参数（Settings）

- **步数**：数值越高，细节通常越好。1-10 步会自动切换到 LCM 极速模式。旁边的三个按钮分别设为 10 / 25 / 45 步
- **宽度 / 高度**：直接设定出图尺寸。每个拉条旁边有数字输入框，**⇄** 交换宽高，下面的按钮是保存好的宽高比（每行四个），点一下同时设定两者。尺寸按 8 的倍数取整；SDXL 在一个百万像素左右训练，所以预设的短边都不低于 1024
- **反向提示词**：默认收起，点标题展开后描述你不希望出现在画面中的内容
- **预设（Preset）**：应用保存好的预设，一次切换整套参数配置
- **采样（Sampling）**：勾选后手动选择采样器与调度器
- **种子**：固定种子可复现同一结果，随机种子每次不同
- **图像数量**：单次生成几张
- **FreeU**：勾选后启用并展开四个系数（B1/B2/S1/S2），两行两列，下面三个预设 **Classic**（1.3 / 1.4 / 0.9 / 0.2）、**Mild**（1.1 / 1.2 / 0.6 / 0.4）、**Conservative**（1.01 / 1.02 / 0.99 / 0.95）一次设好四个。它重新缩放 UNet 的 skip 特征、可增加背景细节；只作用于基础模型，默认关闭
- **引导比例与锐度**：勾选该框后展开 **Guidance Scale**（数值越高越贴近提示词）与 **Image Sharpness**（数值越高纹理越锐，过高会显得不自然）
- **输出格式**：png / jpg / webp

### 模型与 LoRA

- 选择基础模型（仅 SDXL）和精炼器模型
- 精炼器切换步数：控制在第几步切换到精炼器
- 最多可同时加载 5 个 LoRA，每个可独立调节权重

### 分辨率与显存

一次生成要同时装下两样东西：模型本身（Illustrious 连同文本编码器约 6.6 GB，Anima 约 5.4 GB），以及随画面增长的解码预算——约 **4.3 KB/输出像素**，即 1024×1024 需要 4.4 GB、1024×1536 需要 6.6 GB。显存装不下两者时，ReFocus 会在解码前把模型先让出去：解码保持快，代价是下一次生成要花 1.5~2.6 秒把模型搬回来。所以在小显存上分辨率是最主要的旋钮——8 GB 在 1024×1024 附近比较从容，4 GB 不在支持范围内（请用 512×512）。

### 高级（Debug Tools / Control / Inpaint）

> ⚠️ **警告**
>
> 以下参数是为高级用户和调试场景准备的。**如果你不理解某个参数的含义，请不要改动它。** 大多数情况下，保持默认值就能得到很好的结果。错误调整可能导致生成质量下降或产生意外结果。

**Debug Tools（调试工具）**

- **Positive / Negative ADM Guidance Scaler** 与 **ADM Guidance End At Step**：基础模型的 ADM 引导；某个 scaler 设为 1.0 即为关闭
- **Refiner swap method**：精炼器以哪种方式介入（`joint` / `separate` / `vae`）
- **CFG Mimicking from TSNR**：用 TSNR 值模拟 CFG，实际 CFG 高于模拟值时才生效

**Control（控制）**

- **Debug Preprocessors / Skip Preprocessors**：显示预处理后的控制图，或跳过预处理（当你给的图本身就是 canny/深度/裁好的人脸时）
- **Mixing Image Prompt and Vary/Upscale** 与 **Mixing Image Prompt and Inpaint**：让 Image Prompt 槽位也作用于这两种模式
- **Softness of ControlNet**：类似 A1111 的 Control Mode（0.0 关闭）
- **Canny 阈值** 与 **人脸检测置信度**：跟着使用它们的类型走——打开 Image Prompt 标签页、选好类型，再勾选该标签页里的 **Advanced**

**Inpaint（修复）**

- **Debug Inpaint Preprocessing**、**Disable initial latent in inpaint**、**Inpaint Engine**、**Inpaint Denoising Strength**、**Inpaint Respective Field**（0 = 只改遮罩区域，1 = 整张图）、**Mask Erode or Dilate**、**Invert Mask**

> 如果你只是想生成一张好看的图片，**不要碰上面这些参数**。它们的存在是为了解决特定的技术问题，而不是为了日常使用。

## 快捷键与技巧

- **点击生成后**：Stop 会完全终止，Skip 会跳过当前正在生成的一张
- **提示词框**：可直接粘贴包含 JSON 参数的文本，系统会自动识别并显示“加载参数”按钮
- **预设**：在设置面板中选择预设，可快速切换整套参数配置
- **历史记录**：所有生成都会保存在 `outputs/` 文件夹中，并生成一个 HTML 索引页面
